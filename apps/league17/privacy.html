League17 Helper — Privacy Policy

This browser extension (League17, Chrome Web Store item fopdncbnfjpecmefpgipmlbeanflfpmg) does not collect, transmit, or sell any personal user data.

What the extension stores locally

  • UI preferences (panel visibility, log level, overlay toggles)
  • Per-user configuration for optional in-game notifications (Telegram bot token and chat id, ntfy.sh topic) — only when the user explicitly enters them in the extension's Settings pane
  • Aggregated local statistics (counters, timestamps)

All of the above is stored exclusively on the user's device via chrome.storage.sync and localStorage. None of it is transmitted to any server operated by the extension author.

Third-party services reached only if the user opts in

  • api.telegram.org — contacted only if the user has entered a Telegram bot token and triggered a notification.
  • ntfy.sh — contacted only if the user has entered an ntfy topic and enabled that alert sink.

Both calls are made directly from the user's browser to those services. The extension author does not proxy, intercept, or log them.

What the extension never does

  • Does not sell or transfer user data to third parties.
  • Does not use or transfer user data for purposes unrelated to the extension's single purpose (a companion overlay for game.league17.ru).
  • Does not use or transfer user data to determine creditworthiness or for lending purposes.
